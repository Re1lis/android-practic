# Kotlin Practice

Учебные задачи на Kotlin: закрепляю на практике темы из [конспекта](https://github.com/Re1lis/android-learning).

## Что внутри

Задачи по блоку **Kotlin lvl 1**:

- **Переменные и типы:** карточка персонажа, константы, преобразование типов
- **Ввод и вывод:** чтение данных с клавиатуры
- **Операции с числами:** перевод секунд в часы и минуты, расчёт чека со скидкой
- **Условия:** проверка числа на чётность, диапазон и делимость, поиск подстроки в слове

## Как запустить

1. Открыть проект в IntelliJ IDEA
2. Открыть `src/Main.kt`
3. Раскомментировать нужную задачу и нажать ▶ рядом с `fun main()`

> Сейчас все задачи лежат в одном файле. После темы «Функции» каждая станет отдельной функцией.
